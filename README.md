# My Portfolio

Welcome to my personal portfolio! This project showcases my work and skills, built with a focus on high performance, modern design, and an excellent user experience.

---

## 🚀 Tech Stack

This project is built using a modern and efficient stack of technologies:

* **React**: The core library for building dynamic, component-based user interfaces.
* **Vite**: A lightning-fast build tool and development server.
* **TailwindCSS**: A utility-first CSS framework for rapid styling.
* **Embla Carousel**: A lightweight carousel library for creating smooth, touch-friendly sliders.
* **EmailJS**: A service for sending emails directly from the browser without a backend.
* **Radix UI**: A set of accessible, unstyled component primitives.
* **Lucide Icons**: A beautiful, open-source icon library for React.
* **Utilities & Styling**:
    * `class-variance-authority`: A utility for creating dynamic class variants.
    * `clsx`: A tiny utility for constructing className strings conditionally.
    * `tailwind-merge`: A function to intelligently merge Tailwind CSS classes.
* **Routing**:
    * `react-router-dom`: A library for handling navigation and routing in React applications.
* **Animations**:
    * `react-type-animation`: A component for creating a dynamic typing effect.

---

## ✨ Features

* **Dynamic Theme Toggle** 🌑: Seamlessly switch between light and dark modes, with preference saved locally.
* **Enchanting Backgrounds** 💫: Experience animated stars, meteors, subtle scroll effects, and glowing UI elements.
* **Responsive Navigation** 📱: Intuitive menus featuring modern glassmorphism.
* **Smooth Animations** 👨‍💻: Engaging intro animations for a polished user experience.
* **Floating Tech Stack** 📊: Visually appealing display of my skills as floating icons.
* **Direct Links** 🖼️: Easy access to project GitHub repositories and live demos.
* **Streamlined Contact** 📩: Social media integration and a responsive contact form with instant toast notifications.
